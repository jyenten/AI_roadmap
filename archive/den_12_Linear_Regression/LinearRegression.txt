Den 12 - Lineární regrese

Dnes jsem se naučil:
- from sklearn.linear_model import LinearRegression
- train_test_split - rozdělení dat na train/test
- model.fit() - trénování modelu
- model.predict() - předpovědi
- model.coef_ - směrnice přímky
- model.intercept_ - průsečík s osou Y
- mean_squared_error - průměrná chyba modelu
- r2_score - jak dobře model vysvětluje data
- np.linspace() - rovnoměrně rozmístěná čísla
- reshape(-1, 1) - převod 1D na 2D array

Důležité principy:
- model se učí na train datech
- model se testuje na test datech které nikdy neviděl
- R2 blízko 1.0 = dobrý model
- y = ax + b kde a = coef_ a b = intercept_
- předpověď pro nová data = model.predict()
