## Odkazy a údržba / Links and maintenance

Původní cesty `docs/*.md` zůstávají rozcestníky pro starší odkazy. Úplné příručky jsou v `cs/` a `en/`; aktualizuj obě jazykové verze. README, AGENTS a learning log mají jazykové soubory na své původní úrovni repozitáře/projektu.

Original `docs/*.md` paths remain navigation pages for older links. Full guides live in `cs/` and `en/`; keep both languages synchronized. README, AGENTS and the learning log retain language pairs at their original repository/project level.

Pravidla agentů a kurátora v obou jazycích zachovávají stejné hranice schvalování. Přesunuté a české projektové kurátorské pokyny jsou chráněné CI Eval Governance a CODEOWNERS. / Agent and curator rules retain the same approval boundaries in both languages. Moved and Czech project curation instructions remain protected by Eval Governance and CODEOWNERS.
